## 4. M07 lát 1: đăng nhập Google, vai trò, phiên, CSRF, nhật ký thao tác

- **Milestone / nhánh:** M07 · `feat/admin-rbac`.
- **Người / agent thực hiện:** Claude Code. Chủ dự án: "và sau đó bạn tiếp tục làm task nha".
- **Thay đổi gì / ở đâu:**
  - `backend/migrations/0002_admin.up.sql` / `.down.sql`: `users`, `user_auth_identities`, `user_contacts`, `roles` (5 vai trò), `user_roles`, `admin_sessions`, `admin_audit_logs` theo thiết kế database (02-identity, 06-admin). `admin_audit_logs.entity_id` là TEXT (thiết kế ghi UUID) để chứa cả id số của loại địa điểm.
  - Role database mới `gowander_admin`: `infrastructure/postgres/init/02-admin-role.sh` (volume mới), `db.sh admin-role` (volume cũ), `compose.yaml`, `README.md`. API công khai vẫn dùng `gowander_app` chỉ đọc; role admin chỉ INSERT/SELECT trên nhật ký.
  - `backend/internal/admin/` (mới): `admin.go` (kiểu, giao diện), `store.go` (đăng nhập theo danh tính Google đã liên kết, email đã được cấp vai trò, hoặc email khởi tạo khi chưa ai có vai trò; không gộp tài khoản theo email; phiên lưu SHA-256; cấp/thu hồi vai trò, giữ ít nhất một SYSTEM_ADMIN bằng khoá advisory; nhật ký), `auth.go` (Google OIDC, Authorization Code + PKCE + nonce, kiểm chữ ký/issuer/audience; tải cấu hình Google lúc đăng nhập đầu, không lúc khởi động), `handler.go` (middleware phiên, CSRF, vai trò; header bảo mật CSP/no-store; trang đăng nhập, tổng quan, người vận hành, nhật ký), `web/` (template, CSS, htmx 2.0.4 ghim, sha256 `e209dda5…fb447`).
  - `backend/internal/platform/config`: `ADMIN_DATABASE_URL`, `ADMIN_BASE_URL`, `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `ADMIN_BOOTSTRAP_EMAIL` (+ test). `cmd/api/main.go`: pool riêng cho Admin, gắn `/admin`. `go.mod`: `github.com/coreos/go-oidc/v3` v3.17.0, `golang.org/x/oauth2` v0.36.0 (lần `go get` đầu tự hạ `golang-migrate` xuống 4.19.1; đã đưa lại 4.20.1). `.env.example`, `backend/README.md`.
