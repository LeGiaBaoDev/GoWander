- **Người / agent thực hiện:** chủ dự án tạo project Google Cloud mới "GoWander" ("tạo lại từ đầu nha vì hình như cái google client kia khác"), Audience External/Testing, Branding, 3 client (Web, Android, iOS); Claude Code ghi Client ID vào `.env`.
- **Thay đổi gì / ở đâu:** `.env` (không vào Git): `GOOGLE_CLIENT_ID` thay bằng client Web mới, xoá `GOOGLE_CLIENT_SECRET` của project cũ, thêm `GOOGLE_ANDROID_CLIENT_ID`, `GOOGLE_IOS_CLIENT_ID`; không lưu client secret mới. `docs/plans/AUTH-tai-khoan-nguoi-dung.md` mục "Trạng thái cấu hình Google".
- **Bằng chứng:** kiểm tra `.env` chỉ in tên biến: 3 biến đúng dạng `….apps.googleusercontent.com`, không còn biến secret; `git check-ignore .env` xác nhận ngoài Git. Đăng nhập Google thật: chưa kiểm chứng (chưa có code).
- **Rủi ro:** client secret của client Web đã bị dán vào chat; khuyên chủ dự án Reset secret (app không dùng secret).
