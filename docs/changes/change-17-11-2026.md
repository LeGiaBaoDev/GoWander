## 1. CONTENT-EDITOR (phần 1): câu chuyện có block JSON — Editor.js trong Admin, API trả `blocks`, app render native

- **Milestone / nhánh:** CONTENT-EDITOR (theo ADR-041) · `feat/app-accounts`.
- **Người / agent thực hiện:** agent (opencode); chủ dự án chọn "CONTENT-EDITOR (ADR-041)".
- **Thay đổi gì / ở đâu:**
  - `backend/migrations/0015_content_blocks.up.sql` + `.down.sql`: thêm `historical_stories.blocks JSONB`; cấp `UPDATE (blocks)` cho `gowander_admin`. Bảng món ăn giữ chữ thường (đoạn ngắn).
  - `backend/internal/content/blocks.go` (mới): kiểu `Document`/`Block` đúng dạng Editor.js, **kiểm ở server**: chỉ nhận `paragraph`, `header` (cấp 2–3), `list` (ordered/unordered), `quote`, `delimiter`; giới hạn 200 khối, 4.000 ký tự/khối, 20.000 ký tự/toàn bài, 50 mục/danh sách, 500 ký tự/mục. Thẻ HTML trong đoạn bị bỏ thành chữ thường (app render chữ, không render HTML); `Document.Text()` sinh bản chữ để tìm kiếm và cho app cũ; `JSON()` là thứ lưu vào JSONB.
  - `backend/internal/admin`: `GuideItem.Blocks`; câu chuyện đọc/ghi thêm cột `blocks`; `saveGuide` kiểm blocks trước khi lưu, **tự sinh `content` từ blocks** nên tìm kiếm và app cũ vẫn chạy; lỗi block hiện ngay trên form.
  - `backend/internal/admin/web/templates/guide_item.html` + `web/static/editor-story.js` + `web/static/editorjs/` (mới): Editor.js 2.31.7 (5 gói, vendored, xem README trong thư mục) chỉ cho form câu chuyện; textarea vẫn còn làm phương án không-JS và bị ẩn khi editor chạy; lưu bằng `editor.save()` trước khi submit. CSP của Admin thêm `style-src 'unsafe-inline'` (Editor.js tự chèn `<style>`).
  - `backend/internal/discover/guide.go`: `Story.Blocks` trả trong `/api/v1/guide/hcm` (bỏ qua nếu JSON hỏng để không làm sập cả cẩm nang).
  - App: `content/Blocks.kt` (mới) — mô hình block + `StoryBody` render **native** (heading, đoạn, danh sách có dấu •, trích dẫn có thanh màu, đường phân cách), dùng `Palette`/`Text` của Design Kit; `Story` có `blocks`, `Regions.kt` dùng `StoryBody` và tự rơi về `paragraphs` khi chưa có blocks.
- **Bằng chứng (đã chạy):** `go test ./internal/content ./internal/admin ./internal/discover` đạt (10 test mới cho blocks: lọc HTML, từ chối loại lạ/khối rỗng/quá dài, chuẩn hoá cấp tiêu đề, sinh chữ); migrate dev → **version 15**; API trả `blocks` cho câu chuyện đã gắn block (kiểm bằng `curl /api/v1/guide/hcm`); **Android emulator**: mở Cẩm nang TP.HCM › 04 Con người & Văn hoá › câu chuyện, thấy đúng tiêu đề mục in đậm, đoạn văn và hai dòng • — tức app render block thật. `:shared:testAndroidHostTest` và `:shared:iosSimulatorArm64Test` đạt; iOS chỉ kiểm bằng biên dịch, **chưa xem bằng mắt**.
- **Ảnh hưởng / rủi ro:** Editor.js chỉ có công cụ chữ — **ảnh giữa bài chưa làm** (ảnh bìa vẫn là ô tải ảnh riêng); nếu JS lỗi, form quay về textarea và server vẫn lưu chữ. In đậm/link trong một đoạn bị đổi thành chữ thường (đúng giới hạn ADR-041 §6). Dữ liệu mẫu: một câu chuyện trong database dev đang có blocks ví dụ ("Một buổi sáng ở Chợ Lớn") để thử — chủ dự án xoá/sửa tuỳ ý. Seed builder và `GuideHcm.kt` (bản offline) **chưa** sinh blocks; phải làm khi viết nội dung thật.
- **Sửa kèm trong lúc kiểm:** bỏ `required` khỏi textarea nội dung câu chuyện (khi Editor.js ẩn nó, trình duyệt vẫn có thể chặn submit; server đã kiểm nội dung); `TestNoticesGroupRepeats` đổi sang mốc giữa trưa cố định — chạy lúc 00:03 ngày 17-11 thì 5 thông báo cách nhau một phút rơi sang hai ngày nên test đỏ oan (lỗi phụ thuộc giờ, không liên quan blocks).
- **Việc tiếp theo:** phần 2 — khối ảnh trong Editor.js (tải ảnh qua pipeline ADR-035, credit + licence), seed builder + bản offline theo blocks, và ảnh chụp màn iOS. Sau đó tới món ăn nếu chủ dự án muốn.

## 2. CONTENT-EDITOR (phần 2): ảnh nằm trong bài — tải qua Admin, lưu kho ảnh, app hiện khung + ghi công

- **Milestone / nhánh:** CONTENT-EDITOR (ADR-041) · `feat/app-accounts`.
- **Người / agent thực hiện:** agent (opencode). Chủ dự án chọn tiếp phần 2 nhưng lưu ý đang cho nhiều agent chạy song song; thay đổi giữ hẹp, không đụng file ngoài phạm vi (working tree sạch khi bắt đầu).
- **Thay đổi gì / ở đâu:**
  - `backend/migrations/0016_content_images.up.sql` + `.down.sql`: bảng `content_images (key, alt, credit, license, created_by, created_at)` — mỗi ảnh trong bài là một dòng, `credit`/`license` bắt buộc; Admin được SELECT/INSERT/DELETE, vai trò công khai chỉ được đọc bốn cột cần để hiện ảnh.
  - `internal/content/blocks.go`: thêm loại **`image`** (key + alt + credit + licence, `url` chỉ có trong phản hồi); khoá phải đúng dạng `img/<hex>` (chặn `..`, dấu cách, đường dẫn tuyệt đối); ảnh không có ghi công/giấy phép bị từ chối; `Text()` lấy `alt` để tìm kiếm.
  - `internal/admin/content_images.go` + `handler.go`: `POST /admin/blocks/image` nhận multipart **dùng lại `receivePhoto`** (cùng pipeline ADR-035: chỉ JPEG/PNG/WebP, nén lại 480/1600, bỏ EXIF, bắt credit + licence), ghi `content_images`, trả JSON `{key,url,credit,license,alt}` cho editor; mỗi lần tải ghi nhật ký `content.image`. Khi lưu câu chuyện, server kiểm **mọi khoá ảnh còn tồn tại** trước khi ghi.
  - `internal/admin/web/static/editorjs/story-image-tool.js` (mới): tool ảnh cho Editor.js — chọn file, ghi công, chọn giấy phép (lấy từ danh sách của repo), mô tả; tải lên rồi thay bằng ảnh xem trước; block rỗng bị bỏ khi lưu để không chặn submit. `editor-story.js` đăng ký tool và lọc block ảnh chưa có khoá.
  - `internal/discover/guide.go`: khi trả cẩm nang, đổi `key` thành URL đầy đủ (`media.URL`) cho block ảnh.
  - App `content/Blocks.kt`: nhánh `image` — `RemotePhoto` 16:9 + dòng ghi công "credit · license", `alt` làm mô tả cho trình đọc màn hình.
  - Test: `content` (ảnh thiếu ghi công/giấy phép/khoá có `..` bị từ chối), `admin` (`TestBlockImageUpload`: 8×8 PNG → 200, JSON đủ khoá/URL/ghi công, file vào kho, dòng `content_images` được ghi).
- **Bằng chứng (đã chạy):** `go vet ./...`, `go test ./...` (backend) đạt; `:shared:compileAndroidMain`, `:shared:compileKotlinIosSimulatorArm64`, `:shared:testAndroidHostTest`, `:shared:iosSimulatorArm64Test` đạt; migrate dev → **version 16**; API trả block ảnh với URL R2 (`curl /api/v1/guide/hcm`, URL trả **200** từ máy Mac). **Android emulator**: mở câu chuyện thấy tiêu đề, đoạn, **khung ảnh đúng tỉ lệ + dòng ghi công "Ảnh: GoWander · Ảnh của GoWander"** và danh sách •; **ảnh không tải được trên emulator** — mở đúng URL đó bằng Chrome trên emulator cũng trắng, tức máy ảo không tới được miền `r2.dev` (máy Mac thì 200), không phải lỗi renderer. **Chưa kiểm chứng**: tải ảnh từ giao diện Admin (cần mật khẩu Admin để đăng nhập), và iOS bằng mắt.
- **Ảnh hưởng / rủi ro:** ảnh trong bài nằm cùng kho với ảnh địa điểm; xoá dòng `content_images` không xoá file (chưa có màn dọn ảnh mồ côi — ghi lại để làm cùng lúc với dọn ảnh địa điểm). Editor.js chỉ chèn ảnh qua nút "Ảnh" của thanh công cụ; dán ảnh từ clipboard không hỗ trợ.
- **Việc tiếp theo:** thử tải ảnh trong Admin khi có phiên đăng nhập; xem lại trên iOS; seed builder + bản offline (`GuideHcm.kt`) sinh blocks khi nội dung hết DRAFT; dọn ảnh mồ côi.
